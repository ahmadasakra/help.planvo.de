# API & Integrationen

Willkommen zur Planvo API-Dokumentation! Mit der Planvo Booking API können Sie Ihr Planvo-Konto nahtlos in Ihre eigene Website integrieren.

## 🚀 Was kann die Planvo Booking API?

Die Planvo Booking API ermöglicht es Ihnen, Buchungsfunktionen direkt auf Ihrer eigenen Website zu integrieren:

- **📅 Online-Terminbuchung** - Kunden können direkt auf Ihrer Website Termine buchen
- **👥 Mitarbeiter-Auswahl** - Zeigen Sie verfügbare Mitarbeiter an
- **⏰ Echtzeit-Verfügbarkeiten** - Automatische Synchronisation mit Ihrem Planvo-Kalender
- **✉️ Automatische Benachrichtigungen** - E-Mail-Bestätigungen für Kunden und Mitarbeiter
- **📊 Zentrale Verwaltung** - Alle Buchungen erscheinen automatisch in Ihrem Planvo-System

## 🔐 Sicherheit

Ihre API Keys sind sicher verschlüsselt und werden niemals im Klartext gespeichert. Sie haben volle Kontrolle über:

- ✅ Aktivierung/Deaktivierung von Keys
- ✅ Rate Limits (Anfragen pro Minute/Tag)
- ✅ IP-Whitelisting
- ✅ Nutzungsstatistiken
