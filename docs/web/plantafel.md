## 📊 Plantafel öffnen

### Zugriff

1. Klicken Sie im Hauptmenü auf **"Plantafel"**
2. Oder: Innerhalb eines Projekts → Tab **"Plantafel"**

**Ansichts-Optionen:**
- 📅 **Woche** - Wochenansicht (Standard)
- 📅 **Monat** - Monatsansicht
- 📅 **Quartal** - Quartalsansicht
- 👥 **Mitarbeiter** - Nach Mitarbeiter gruppiert
- 📊 **Projekt** - Nach Projekt gruppiert

---

## 👥 Ressourcen zuweisen

### Zuweisung per Drag & Drop

**Einfache Zuweisung:**
1. Ziehen Sie ein **Projekt** aus der linken Liste
2. Ziehen Sie es auf einen **Mitarbeiter** in der Plantafel
3. Drop auf gewünschtes **Datum**
4. Dialog öffnet sich:
   - 📅 **Startdatum** (automatisch)
   - 📅 **Enddatum** (automatisch)
   - ⏱️ **Stunden** (optional)
   - 📄 **Beschreibung** (optional)
5. Klicken Sie auf **"Zuweisen"**

### Manuelle Zuweisung

1. Klicken Sie auf einen **freien Slot** in der Plantafel
2. Wählen Sie:
   - 📊 **Projekt**
   - 👤 **Mitarbeiter**
   - 📅 **Zeitraum**
   - ⏱️ **Stunden** (optional)
3. Klicken Sie auf **"Zuweisen"**

### Mehrere Mitarbeiter zuweisen

**Team-Zuweisung:**
1. Wählen Sie Projekt
2. Klicken Sie auf **"Team zuweisen"**
3. Wählen Sie mehrere Mitarbeiter
4. Definieren Sie Zeitraum
5. Klicken Sie auf **"Zuweisen"**

## 📈 Auslastung überwachen

### Auslastungs-Anzeige

**Farbcodierung:**
- 🟢 **Grün** (0-80%) - Normal ausgelastet
- 🟡 **Gelb** (80-100%) - Voll ausgelastet
- 🔴 **Rot** (>100%) - Überlastet!

**Beispiel:**
```
Max Mustermann
├─ KW 45: ████████░░  80%  (32h von 40h)
├─ KW 46: ██████████  100% (40h von 40h)
└─ KW 47: ███████████ 110% (44h von 40h) ⚠️ ÜBERLASTET!
```

### Auslastungs-Statistiken

**Team-Übersicht:**
```
📊 Team-Auslastung (KW 45)
├─ Max:       80%  ✅
├─ Anna:      100% ⚠️
├─ Tom:       60%  ✅
├─ Lisa:      120% 🔴 ÜBERLASTET!
└─ Durchschnitt: 90%
```

### Warnungen

**Automatische Warnungen bei:**
- ⚠️ Überlastung (>100%)
- ⚠️ Überschneidungen
- ⚠️ Fehlende Zuweisungen
- ⚠️ Unrealistische Planung

## ⚠️ Konflikte erkennen

### Überschneidungen

**Automatische Erkennung:**
- System warnt bei Überschneidungen
- Rote Markierung im Kalender
- Tooltip zeigt Details

**Konflikt-Details:**
```
⚠️ Konflikt erkannt!
├─ Max Mustermann
├─ Projekt A: 15.12. - 20.12.2024
├─ Projekt B: 18.12. - 22.12.2024
└─ Überschneidung: 3 Tage
```

### Konflikte lösen

**Optionen:**
1. **Zuweisung verschieben** - Anderes Datum wählen
2. **Mitarbeiter wechseln** - Anderen Mitarbeiter zuweisen
3. **Projekt aufteilen** - Projekt in Phasen aufteilen
4. **Ignorieren** - Konflikt akzeptieren (nicht empfohlen)

## 📅 Zeitplanung

### Wochenansicht

**Standard-Ansicht:**
```
         │  Mo 02  │  Di 03  │  Mi 04  │  Do 05  │  Fr 06
─────────┼─────────┼─────────┼─────────┼─────────┼─────────
Max M.   │ ████░░░ │ ███████ │ ███████ │ ████░░░ │ ░░░░░░░
Anna K.  │ ███████ │ ███████ │ ███████ │ ███████ │ ███████
Tom S.   │ ░░░░░░░ │ ████░░░ │ ███████ │ ███████ │ ███████
```

**Legende:**
- █ = Eingeplant
- ░ = Verfügbar
- ⚠️ = Überlastet

### Monatsansicht

**Übersichtlicher Monatskalender:**
- Alle Mitarbeiter auf einen Blick
- Projekte farbcodiert
- Auslastung sichtbar

## ✏️ Zuweisungen bearbeiten

### Zuweisung ändern

1. Klicken Sie auf eine **Zuweisung** in der Plantafel
2. Dialog öffnet sich
3. Ändern Sie:
   - 📅 Datum
   - ⏱️ Stunden
   - 📄 Beschreibung
4. Klicken Sie auf **"Speichern"**

### Zuweisung löschen

1. Klicken Sie auf Zuweisung
2. Klicken Sie auf **"Löschen"**
3. Bestätigen Sie

**Oder:**
- Zuweisung aus Plantafel ziehen
- In "Löschen"-Bereich ablegen

---

## 📊 Berichte & Export

### Auslastungsbericht

1. Klicken Sie auf **"Bericht erstellen"**
2. Wählen Sie:
   - 👥 Mitarbeiter/Team
   - 📅 Zeitraum
   - 📊 Inhalt (Auslastung, Projekte, etc.)
3. Klicken Sie auf **"Exportieren"**

**Formate:**
- 📄 PDF
- 📊 Excel
- 📋 CSV

### Export

**Plantafel exportieren:**
1. Klicken Sie auf **"Exportieren"**
2. Wählen Sie Format:
   - 📄 PDF (für Präsentation)
   - 📊 Excel (für weitere Bearbeitung)
3. Klicken Sie auf **"Herunterladen"**

## ❓ Häufige Fragen

### Kann ich mehrere Projekte gleichzeitig zuweisen?

Ja, ein Mitarbeiter kann mehrere Projekte gleichzeitig bearbeiten. Achten Sie auf die Gesamtauslastung.

### Wie funktioniert die automatische Konflikt-Erkennung?

Das System prüft automatisch auf Überschneidungen und warnt Sie bei Konflikten.

### Kann ich die Plantafel drucken?

Ja, klicken Sie auf **"Drucken"** - die Plantafel wird als PDF generiert.

### Wie kann ich die Auslastung reduzieren?

- Projekte verschieben
- Zusätzliche Mitarbeiter zuweisen
- Projekt-Scope reduzieren
