## 🎯 Was ist das Dashboard?

Das Dashboard ist Ihre **persönliche Startseite** in Planvo. Hier sehen Sie auf einen Blick alle wichtigen Informationen:

- 📊 Ihre aktuellen Projekte
- ⏰ Laufende Zeiterfassung
- 📅 Anstehende Schichten
- ✅ Offene Aufgaben
- 📢 Wichtige Benachrichtigungen
- 📈 Persönliche Statistiken

## 🧭 Dashboard-Bereiche

### 1. Header (Kopfzeile)

**Oben links:**
- 🏠 **Planvo-Logo** - Zurück zum Dashboard
- 📋 **Hauptnavigation** - Zugriff auf alle Bereiche

**Oben rechts:**
- 🔔 **Benachrichtigungen** - Neue Nachrichten und Updates
- 👤 **Profilmenü** - Einstellungen und Abmelden
- 🔍 **Suche** - Schnell finden, was Sie brauchen

---

### 2. Willkommensbereich

```
Guten Morgen, [Ihr Name]! 👋
Heute ist Montag, 4. November 2024
```

Zeigt:
- Persönliche Begrüßung
- Aktuelles Datum
- Wetter (optional)

---

### 3. Zeiterfassung-Widget

⏰ **Schnell-Zugriff zur Zeiterfassung**

**Wenn Sie NICHT eingestempelt sind:**
- Grüner Button: **"Arbeit starten"**
- Zeigt letzte Arbeitszeit

**Wenn Sie eingestempelt sind:**
- Rote Uhr: **Laufende Arbeitszeit** (z.B. 03:24:15)
- Orange Button: **"Pause starten"**
- Roter Button: **"Arbeitsende"**

### 4. Aktuelle Projekte

📊 **Ihre Projekte im Überblick**

Zeigt bis zu 5 aktuelle Projekte mit:
- Projektname
- Status (🟢 Aktiv, 🟡 In Planung, 🔴 Überfällig)
- Fortschrittsbalken
- Fälligkeitsdatum
- Anzahl offener Aufgaben

**Beispiel:**
```
🏗️ Büroumbau Hamburg
├─ Status: 🟢 Aktiv
├─ Fortschritt: ████████░░ 75%
├─ Fällig: 15.12.2024
└─ Aufgaben: 5 offen
```

## 🎨 Dashboard personalisieren

Sie können Ihr Dashboard anpassen:

### Widgets verschieben

1. Klicken Sie oben rechts auf **⚙️ Dashboard anpassen**
2. Ziehen Sie Widgets mit der Maus
3. Klicken Sie auf **"Speichern"**

### Widgets ein-/ausblenden

1. Klicken Sie auf **⚙️ Dashboard anpassen**
2. Aktivieren/Deaktivieren Sie Widgets
3. Klicken Sie auf **"Speichern"**

**Verfügbare Widgets:**
- ✅ Zeiterfassung
- ✅ Projekte
- ✅ Aufgaben
- ✅ Schichten
- ✅ Benachrichtigungen
- ✅ Statistiken
- ✅ Wetter
- ✅ Geburtstage

## 💡 Produktivitäts-Tipps

!!! tip "Tipp 1: Morgen-Routine"
    Starten Sie jeden Tag mit einem Blick aufs Dashboard:
    
    1. ✅ Benachrichtigungen prüfen
    2. ⏰ Arbeitszeit stempeln
    3. 📋 Aufgaben für heute priorisieren
    4. 📅 Schicht-Details prüfen

!!! tip "Tipp 2: Schnellzugriffe nutzen"
    Pinnen Sie häufig genutzte Aktionen in die Schnellzugriffsleiste für schnelleren Zugriff.

!!! tip "Tipp 3: Dashboard als Startseite"
    Machen Sie das Planvo-Dashboard zu Ihrer Browser-Startseite für direkten Zugriff.

## ❓ Häufige Fragen

### Warum sehe ich keine Projekte?

**Mögliche Gründe:**
- Sie sind noch keinem Projekt zugeordnet
- Sie haben nicht die nötigen Berechtigungen
- Es wurden noch keine Projekte erstellt

**Lösung:** Kontaktieren Sie Ihren Projektleiter oder Administrator.

### Wie aktualisiere ich das Dashboard?

**Web:** Drücken Sie `F5` oder klicken Sie auf das 🔄 Symbol

**Mobile:** Wischen Sie auf dem Dashboard nach unten (Pull-to-Refresh)

### Kann ich mehrere Dashboard-Layouts speichern?

Ja! Unter **Einstellungen** → **Dashboard** → **Layouts** können Sie verschiedene Layouts für unterschiedliche Arbeitsmodi erstellen.
