## 📧 E-Mail Support

### support@planvo.de

Schreiben Sie uns eine E-Mail mit:

**Bitte geben Sie an:**
- 📝 Beschreibung Ihres Problems
- 🏢 Ihre Firma/Organisation
- 👤 Ihr Name und E-Mail
- 📱 Gerät und Browser/App-Version
- 📸 Screenshots (wenn hilfreich)

**Beispiel:**
```
Betreff: Problem bei der Zeiterfassung

Hallo Planvo-Team,

ich habe ein Problem mit der Zeiterfassung.
Wenn ich auf "Arbeit starten" klicke, passiert nichts.

Meine Informationen:
- Firma: Musterfirma GmbH
- Gerät: iPhone 13, iOS 17
- App-Version: 1.6.6

Im Anhang finden Sie einen Screenshot.

Mit freundlichen Grüßen
Max Mustermann
```

## 🐛 Bug melden

Haben Sie einen Fehler gefunden?

### So melden Sie einen Bug:

1. **E-Mail an:** [bugs@planvo.de](mailto:bugs@planvo.de)
2. **Betreff:** "Bug: [Kurze Beschreibung]"
3. **Inhalt:**

**Bug-Bericht-Vorlage:**
```
📱 Gerät/Browser:
iOS 17 / Chrome 120 / etc.

🔢 App-Version:
1.6.6

📍 Wo tritt der Bug auf?
Zeiterfassung → Arbeit starten

🔄 Schritte zur Reproduktion:
1. Schritt 1
2. Schritt 2
3. Schritt 3

❌ Erwartetes Verhalten:
Button sollte Zeit starten

🐛 Tatsächliches Verhalten:
Button reagiert nicht

📸 Screenshots:
[Anhang]

📝 Zusätzliche Informationen:
Problem tritt nur bei bestimmtem Projekt auf
```

**Wir belohnen Bug-Melder!**
Für gemeldete Bugs erhalten Sie:
- 🙏 Unseren Dank
- 🎁 Kleine Aufmerksamkeit (bei kritischen Bugs)
- 📢 Erwähnung im Changelog (optional)

## ❓ Häufig gestellte Support-Fragen

### Wie schnell erhalte ich Hilfe?

Bei kritischen Problemen (z.B. Login nicht möglich) innerhalb von 2 Stunden. Für allgemeine Fragen innerhalb von 24 Stunden.

### Kostet der Support etwas?

Nein! Der Support ist im Planvo-Abonnement enthalten und komplett kostenlos.

### In welchen Sprachen bieten Sie Support?

Aktuell auf Deutsch und Englisch.

### Kann ich auch am Wochenende Support erhalten?

Standard-Support ist Mo-Fr verfügbar. Enterprise-Kunden haben 24/7-Support.
