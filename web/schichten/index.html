    Schichtplanung (Web)¶

    ⏱️ Lesezeit: 7 Minuten
    📱 Verfügbar in: Web & Mobile
    👤 Für: Schichtplaner, Mitarbeiter

    📋 Was Sie in diesem Kapitel lernen¶

    • ✅ Wie Sie Schichten erstellen und verwalten
    • ✅ Wie Sie Mitarbeiter Schichten zuweisen
    • ✅ Wie Schichtbewerbungen funktionieren
    • ✅ Wie Sie die Anwesenheit bestätigen
    • ✅ Wie Sie Schichtpläne exportieren

    🎯 Übersicht¶

    Die Schichtplanung in Planvo hilft Ihnen bei:

    • 📅 Schichtpläne erstellen - Flexible Planung
    • 👥 Mitarbeiter zuweisen - Automatische Vorschläge
    • 📱 Schichtbewerbungen - Mitarbeiter können sich bewerben
    • ✅ Anwesenheit tracking - Check-in/Check-out
    • 📊 Auswertungen - Schichtstatistiken
    • 🔔 Benachrichtigungen - Automatische Updates

    📅 Schichten ansehen¶

    Kalender-Ansicht¶

    1. Klicken Sie im Hauptmenü auf "Schichten"
    2. Sie sehen einen Kalender mit allen Schichten

    Ansichts-Optionen: - 📅 Tagesansicht - Detailliert für einen Tag - 📅 Wochenansicht - Überblick über die Woche - 📅 Monatsansicht - Langfristige Planung - 📋 Listenansicht - Alle Schichten als Liste

    Schicht-Details¶

    Klicken Sie auf eine Schicht, um Details zu sehen:

    📅 Frühschicht - Montag, 04.11.2024

⏰ Zeit
├─ 06:00 - 14:00 Uhr (8 Stunden)
└─ Pause: 30 Minuten

📍 Standort
└─ Hamburg Zentrale

👥 Team (5/6 Mitarbeiter)
├─ ✅ Max Mustermann (Schichtleiter)
├─ ✅ Anna Schmidt
├─ ✅ Tom Weber
├─ ✅ Lisa Müller
├─ ⏳ Sarah Klein (Bewerbung ausstehend)
└─ ❌ [1 Platz frei]

📝 Beschreibung
└─ Warenannahme und Inventur

    ➕ Neue Schicht erstellen¶

    Einzelne Schicht¶

    1. Klicken Sie auf "+ Neue Schicht"
    2. Füllen Sie die Details aus:

    Zeitangaben: - 📅 Datum - 🕐 Startzeit (z.B. 06:00) - 🕐 Endzeit (z.B. 14:00) - ☕ Pausenzeit (z.B. 30 Min)

    Schicht-Details: - 📝 Schichtname (z.B. "Frühschicht") - 📍 Standort (aus Liste wählen) - 👥 Benötigte Mitarbeiter (z.B. 5) - 🎨 Farbe (für Kalender)

    Zusatzinformationen: - 📄 Beschreibung (Aufgaben, Besonderheiten) - 🏷️ Tags (z.B. "Produktion", "Service") - ⚠️ Qualifikationen (erforderliche Skills)

    1. Klicken Sie auf "Schicht erstellen"

    Wiederkehrende Schichten¶

    Für regelmäßige Schichten:

    1. Erstellen Sie eine Schicht wie oben
    2. Aktivieren Sie "Wiederkehrend"
    3. Wählen Sie Muster:
    4. 📅 Täglich (Mo-So)
    5. 📅 Werktags (Mo-Fr)
    6. 📅 Wöchentlich (z.B. jeden Montag)
    7. 📅 Monatlich (z.B. jeden 1.)

    8. 📅 Benutzerdefiniert

    9. Definieren Sie Ende:

    10. Nach X Wiederholungen
    11. Bis zu einem Datum
    12. Unbegrenzt

    Beispiel: 

    Frühschicht Mo-Fr
├─ 06:00 - 14:00 Uhr
├─ Wiederholt sich: Werktags (Mo-Fr)
├─ Startet am: 04.11.2024
├─ Endet am: 31.12.2024
└─ Erstellt: 57 Schichten

    Schichtvorlagen¶

    Sparen Sie Zeit mit Vorlagen:

    1. Erstellen Sie eine Schicht
    2. Klicken Sie auf "Als Vorlage speichern"
    3. Geben Sie der Vorlage einen Namen

    Vorlage verwenden: 1. "+ Neue Schicht" 2. Wählen Sie "Aus Vorlage" 3. Wählen Sie die gewünschte Vorlage 4. Passen Sie Datum/Details an 5. Erstellen

    👥 Mitarbeiter zuweisen¶

    Manuelle Zuweisung¶

    1. Öffnen Sie eine Schicht
    2. Klicken Sie auf "+ Mitarbeiter hinzufügen"
    3. Wählen Sie Mitarbeiter aus der Liste
    4. Weisen Sie eine Rolle zu:
    5. 👑 Schichtleiter - Verantwortlich für die Schicht

    6. 👷 Mitarbeiter - Reguläres Teammitglied

    7. Klicken Sie auf "Hinzufügen"

    Der Mitarbeiter erhält automatisch eine Benachrichtigung.

    Automatische Vorschläge¶

    Planvo schlägt passende Mitarbeiter vor basierend auf:

    • ✅ Verfügbarkeit (keine Konflikte)
    • ✅ Qualifikationen (erforderliche Skills)
    • ✅ Arbeitszeit-Auslastung (nicht überlastet)
    • ✅ Standort (gleicher/naher Standort)
    • ✅ Präferenzen (bevorzugte Schichtzeiten)
    Vorgeschlagene Mitarbeiter:

├─ ✅ Verfügbar
├─ ✅ Auslastung: 80%
└─ ✅ Wohnt in Hamburg

🟢 Anna Schmidt (90% Match)
├─ ✅ Qualifikation: Schichtleiter
├─ ✅ Verfügbar
├─ ⚠️ Auslastung: 95%
└─ ✅ Wohnt in Hamburg

├─ ✅ Verfügbar
├─ ⚠️ Keine Qualifikation
├─ ✅ Auslastung: 60%

    📝 Schichtbewerbungen¶

    Offene Schichten veröffentlichen¶

    1. Erstellen Sie eine Schicht
    2. Aktivieren Sie "Offen für Bewerbungen"
    3. Definieren Sie Bewerbungsfrist
    4. Veröffentlichen Sie die Schicht

    Mitarbeiter können sich bewerben: - Über die Web-Version - Über die Mobile App - Erhalten Push-Benachrichtigung

    Bewerbungen verwalten¶

    1. Öffnen Sie die Schicht
    2. Tab "Bewerbungen" (zeigt Anzahl)
    3. Sie sehen alle Bewerbungen:
    📝 Bewerbungen (5)

├─ Qualifikation: ✅ Erfüllt

├─ Beworben: 01.11.2024 14:20
├─ Qualifikation: ✅ Erfüllt
├─ Verfügbarkeit: ✅ Ja
└─ Nachricht: "Möchte gerne Frühschicht"

❌ Tom Weber
├─ Beworben: 02.11.2024 08:15

    ✅ Anwesenheit bestätigen¶

    Check-in/Check-out¶

    Mitarbeiter stempeln: 1. Öffnen Schicht in Mobile App 2. Tippen auf "Schicht beginnen" 3. Optional: GPS-Standort wird erfasst 4. Am Ende: "Schicht beenden"

    Als Schichtleiter sehen Sie: 

    👥 Anwesenheit (5/6)

✅ Max (Schichtleiter)
├─ Check-in: 05:55 Uhr
└─ Status: Anwesend

✅ Anna
├─ Check-in: 06:02 Uhr
└─ Status: Anwesend

✅ Tom
├─ Check-in: 06:00 Uhr
└─ Status: In Pause

⏳ Lisa
└─ Noch nicht eingestempelt

❌ Sarah
└─ Abwesend (krank gemeldet)

    Manuelle Anwesenheit¶

    Schichtleiter können Anwesenheit manuell eintragen:

    1. Öffnen Sie die Schicht
    2. Tab "Anwesenheit"
    3. Wählen Sie Mitarbeiter
    4. Setzen Sie Status:
    5. ✅ Anwesend
    6. ⏰ Verspätet (mit Uhrzeit)
    7. ❌ Abwesend (mit Grund)
    8. 🤒 Krank
    9. 🏖️ Urlaub

    📥 Schichtpläne exportieren¶

    Export-Optionen¶

    1. Gehen Sie zu Schichten → Export
    2. Wählen Sie Zeitraum
    3. Wählen Sie Format:

    PDF: - Druckfertiger Schichtplan - Für Aushang im Betrieb - Mit Unterschriftsfeld

    Excel: - Zum Weiterverarbeiten - Auswertungen erstellen - Lohnabrechnungsdaten

    iCal: - Für Kalender-Apps (Apple, Google, Outlook) - Automatische Synchronisation - Mit Erinnerungen

    🔔 Benachrichtigungen¶

    Automatische Benachrichtigungen¶

    Mitarbeiter werden automatisch benachrichtigt bei:

    • 📢 Neuer Schichtzuweisung
    • 📝 Schichtänderung (Zeit, Standort)
    • ❌ Schichtabsage
    • ⏰ Schichterinnerung (24h vorher)
    • ✅ Genehmigte Bewerbung
    • ❌ Abgelehnte Bewerbung

    Erinnerungen konfigurieren¶

    Unter Einstellungen → Schichten:

    • 🔔 Erinnerung 24h vor Schichtbeginn
    • 🔔 Erinnerung 1h vor Schichtbeginn
    • 🔔 Erinnerung bei offenen Schichten
    • 🔔 Erinnerung bei fehlender Anwesenheit

    ⚙️ Schicht-Einstellungen¶

    Globale Einstellungen¶

    Schichttypen definieren: 

    Frühschicht:  06:00 - 14:00 Uhr
Spätschicht:  14:00 - 22:00 Uhr
Nachtschicht: 22:00 - 06:00 Uhr

    Pausenregelungen: - Automatische Pausen-Berechnung - Gesetzliche Mindestpausen - Bezahlte/Unbezahlte Pausen

    Qualifikationen: - Staplerfahrer - Schichtleiter - Erste-Hilfe - etc.

    💡 Best Practices¶

    Tipp 1: Frühzeitig planen

    Erstellen Sie Schichtpläne mindestens 2 Wochen im Voraus für bessere Planbarkeit.

    Tipp 2: Bewerbungen nutzen

    Lassen Sie Mitarbeiter sich für Schichten bewerben - das erhöht die Motivation und Flexibilität.

    Tipp 3: Fairness wahren

    Verteilen Sie beliebte und unbeliebte Schichten gerecht im Team.

    Tipp 4: Qualifikationen pflegen

    Halten Sie Mitarbeiter-Qualifikationen aktuell für bessere Vorschläge.

    ❓ Häufige Fragen¶

    Kann ich Schichten tauschen?¶

    Ja! Mitarbeiter können untereinander Schichten tauschen (mit Genehmigung des Schichtleiters).

    Was passiert bei Krankheit?¶

    Krankmeldungen gehen automatisch an den Schichtleiter, der dann Ersatz finden kann.

    Können Mitarbeiter Wunschschichten angeben?¶

    Ja, unter Profil → Verfügbarkeit können Präferenzen angegeben werden.

    Wie werden Überstunden berechnet?¶

    Überstunden über die vertraglich vereinbarte Wochenarbeitszeit hinaus werden automatisch berechnet.
